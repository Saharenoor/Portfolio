Core CS

GitHub Lite — Git-Like Version Control System

A console-based, Git-inspired version control system written in C++ that supports commits, branching, merging, rollback, and file tracking — built without any external VCS libraries, just core data structures.

Red-Black Trees keep the commit index balanced for fast lookups, Stacks power undo/rollback history, Queues process commit logs in order, BSTs handle file lookups, Linked Lists chain branch histories together, and a Heap prioritizes changes during merges.

Robotics

Embedded Systems: Arduino Smart Car

A remote-controlled car built on Arduino with an onboard flame sensor for real-time fire detection and an actuated extinguishing mechanism that triggers automatically once a flame is sensed nearby.

The build combines embedded C++ for the sensor-read-and-respond loop with basic motor control logic, turning a hobby RC platform into a small safety-focused robot.
